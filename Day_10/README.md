# DAY 10 — Tensors: Basic Concepts

## 1. What is a Tensor?

**Definition:**  
A Tensor is a **multi-dimensional array of numerical values** used to represent and process data, especially in Machine Learning and Deep Learning.

Think:

```text
Scalar → 0D
Vector → 1D
Matrix → 2D
Tensor → 3D and above
```

Technically, scalar, vector and matrix are also tensors of different ranks.

---

# 2. 0D Tensor / Scalar

**Definition:**  
A 0D tensor contains **only one value** and has no axis.

Example:

```text
5
```

Rank:

```text
0
```

---

# 3. 1D Tensor / Vector

**Definition:**  
A 1D tensor contains values arranged along **one axis** and is commonly called a vector.

Example:

```text
[1, 2, 3, 4]
```

Rank:

```text
1
```

Shape:

```text
(4,)
```

---

# 4. 2D Tensor / Matrix

**Definition:**  
A 2D tensor contains values arranged along **two axes**, typically represented as rows and columns, and is commonly called a matrix.

Example:

```text
[1 2 3]
[4 5 6]
```

Rank:

```text
2
```

Shape:

```text
(2,3)
```
