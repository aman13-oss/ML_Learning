# DAY 9 — Real-Life ML Applications

## 1. Retail — Amazon / Big Bazaar

**Definition:**  
Retail companies use ML to understand customer behavior and perform tasks such as **recommendation, demand forecasting, customer segmentation and personalized offers**.

### Example

You search for running shoes multiple times.

The system may learn your interest and recommend:

```text
Running Shoes
Sports Socks
Running T-shirt
Sports Watch
```

---

# 2. Banking & Finance

**Definition:**  
Banking and finance companies use ML for **fraud detection, credit scoring, risk assessment, loan decisions and customer analysis**.

### Example

A bank notices that a transaction is very different from a customer's normal behavior.

ML:

```text
Transaction Pattern
       ↓
Anomaly/Fraud Detection
```

---

# 3. Transportation — Ola

**Definition:**  
Transportation platforms use ML for **demand prediction, driver-rider matching, route optimization and dynamic pricing**.

### Example

Suppose a stadium event is ending.

The system predicts:

```text
Very High Rider Demand
```

and can use that prediction for driver positioning and pricing decisions.

---

# 4. Manufacturing — Tesla

**Definition:**  
Manufacturing companies use ML for **quality control, defect detection, predictive maintenance and production optimization**.

### Example

Machine sensors continuously generate:

```text
Temperature
Pressure
Vibration
```

ML can detect patterns that indicate a possible machine failure.

---

# 5. Consumer Internet — Twitter/X

**Definition:**  
Consumer Internet platforms use ML for **content recommendation, personalized feeds, spam detection and user behavior analysis**.

### Example

If you frequently interact with technology-related posts, the recommendation system may learn that preference and show more relevant technology content.
